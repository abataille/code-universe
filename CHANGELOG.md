# Changelog

All notable user-facing changes to Code Universe are recorded here.

## 0.2.0 — 2026-09-01

### Added

- Multi-language project scanning for Swift, JavaScript, TypeScript, HTML, CSS,
  Python, PHP, Java, C#, Objective-C, and Objective-C++.
- TypeScript semantic relationships, web-asset mapping, project-asset discovery,
  and a versioned graph schema.
- Optional Tree-sitter WASM parsing and parser comparison for supported languages.
- Expanded city hierarchy, exact source ranges, project analysis, and improved
  review-trace visualization.
- Self-contained Electron/Chromium Mac packaging and signed, notarized DMG release
  automation.
- BSL 1.1 source licensing and separate commercial-licensing documentation.
- Offline Ed25519 verification for Pro and Team licence documents.
- Local licence-status and activation endpoints.
- In-app licence status and signed-document import flow.
- External-only key-generation and commercial licence-issuance tools.
- Xcode project wrapper for development and signed release builds.
- Product strategy, public roadmap, contribution guidance, security policy,
  issue forms, pull-request template, and continuous integration.
- Patched transitive dependency versions for the current npm security advisories.

### Changed

- Positioned Code Universe as a local architecture and AI-agent review workspace.
- Identified Dr. Raymund Vorwerk as legal licensor and VCLab as publisher/brand.
- Prioritized public-preview validation and real repository feedback before paid
  feature gates or payment automation.

### Security

- Added repository checks that reject tracked private signing keys.
- Pinned patched transitive dependency versions; the production dependency audit
  reports no known vulnerabilities at release preparation time.

## 0.1.0 — 2026-07-24

### Added

- Initial public Code Universe repository and local Mac architecture visualizer.
